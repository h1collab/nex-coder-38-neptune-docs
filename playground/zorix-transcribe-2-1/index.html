The browser sends the selected or recorded audio as multipart/form-data. For verbose_json, the current documented response shape is {"task":"transcribe","language":null,"duration":null,"text":"..."}.

Basic request

curl -sS \
  'https://chat.zorix.it/v1/audio/transcriptions' \
  -F 'file=@record.webm' \

Verbose JSON

curl -sS \
  'https://chat.zorix.it/v1/audio/transcriptions' \
  -F 'file=@record.webm' \ \
  -F 'response_format=verbose_json' \
  | jq
