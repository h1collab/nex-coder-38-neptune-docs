OpenAI key handling: this static playground uses your OpenAI API key directly in the browser and does not save it to localStorage. Do not use a long-lived production key on a public/shared device. For production use, route OpenAI requests through your own server-side proxy.

Zorix uses https://chat.zorix.it/v1/chat/completions and the public label Gpt6.1sol. In the current Zorix API, streaming uses custom SSE events such as event: delta with {"text":"..."}. The playground parses that format separately from OpenAI's standard chat-completion chunks.

What is being compared

The playground sends the same user message and optional system prompt to both providers. Zorix receives model: "Gpt6.1sol". OpenAI receives the model ID you enter.

For Zorix, this page also tracks previous_response_id during the current page session. Use “Clear results / reset Zorix conversation” to remove that continuity before another independent test.

Zorix request

POST https://chat.zorix.it/v1/chat/completions

{
  "model": "Gpt6.1sol",
  "messages": [
    {"role":"user","content":"..."}
  ],
  "stream": true
}

Important limitation

This is a browser-based comparison tool, not a benchmark. Network path, provider load, browser scheduling, account settings, model configuration, and streaming format can all affect the timings shown here.

If the browser blocks direct OpenAI requests, use a server-side OpenAI proxy and update the playground endpoint rather than exposing a production API key in frontend code.
