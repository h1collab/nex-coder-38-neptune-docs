Zorix Code Is Officially Released

Zorix Code is moving from preparation into an official desktop release, beginning with Windows.
Official release

Today, we are officially releasing Zorix Code.

Zorix Code is available now on Windows.

The first desktop release is the Windows x64 build, following the Windows-first rollout we announced earlier.

Zorix Code is built around real software engineering work: understanding repositories, planning changes, working with files and terminal workflows, implementing changes, and reviewing the result in context.

Download Zorix Code for Windows x64 →

The current Windows build is distributed through the official Zorix Code GitHub Release installer.

This release is a starting point, not the end of the product. We will continue improving Zorix Code based on real usage and community feedback.

Additional platform plans and future release details will be announced separately when they are ready.

From Early Access to a desktop release. Zorix Code is here.
— Zorix
