Official announcement · October 8, 2026

Zorix Code Desktop Is Coming Soon

We are preparing a desktop version of Zorix Code, with Windows planned as the first platform.
Official notice

We are preparing to bring Zorix Code to the desktop.

Zorix Code Desktop is coming soon.

The desktop release will begin with Windows. Windows is currently our priority for the first public desktop version.

The goal is to make Zorix Code feel more native to the development environment: closer to local projects, files, terminal workflows, and the day-to-day work of building software.

We are not announcing a final release date in this notice.

We are also not publishing timelines for additional desktop platforms yet. Those details will be shared when they are ready.

Windows first. Zorix Code Desktop next.

As the desktop version moves closer to release, we will share more about availability, supported workflows, and how it will fit alongside the existing Zorix Code experience.

— Zorix
