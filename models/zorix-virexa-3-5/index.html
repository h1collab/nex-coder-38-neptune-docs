Overview

Virexa 3.5 is the current released Virexa generation.

Virexa 3.5 was officially released on October 6, 2026. It supports text input and image output, with High as the current quality mode. Image-to-image remains in internal testing.

Input

Text

Prompts are provided as text. Image input is not part of the currently released public workflow.

Output

Image

Virexa 3.5 produces one image per generation in the current release.

Quality

High

The current public quality setting is High.

Testing

img2img

Image-to-image remains in internal testing and is not part of the current public release.

Model details

A focused image model with a simpler public surface.

Virexa 3.5 does not expose multiple effort levels. The current released experience is centered on High quality text-to-image generation.
