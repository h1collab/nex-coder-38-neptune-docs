Overview

Zorix Virexa 3.5 is a preview image-generation model focused on substantially higher visual quality.

This preview improves image generation quality while retaining a simple text-to-image workflow.

Higher generation quality

Virexa 3.5 introduces a significant improvement in overall image quality compared with previous Virexa generations, with greater emphasis on visual coherence, detail and generation fidelity.

Modalities

The current Virexa 3.5 Preview supports text prompts as input and generated images as output.

Generated image provenance

Images generated with Virexa may include provenance signals intended to help identify AI-generated content.

Generated content notice

Generated by the Zorix Virexa model. Additional provenance markers, including SynthID and a Zorix watermark, may be present by design to help identify AI-generated content. If a watermark is detected, this is expected.

API

Zorix Virexa 3.5 does not currently support public API access. No API model identifier or API pricing has been announced.

The current Preview can be used through Zorix Chat.
