Nex Coder 3.8 Preview — Neptune is the depth-oriented profile of Zorix's AA4 / Zorix4 generation. It is designed for difficult coding work spanning repositories, tools, execution environments, long decision chains, and verification-heavy engineering workflows.

Neptune is currently a preview profile with staged availability. Model visibility can vary between Zorix Code accounts.

Capabilities

Neptune is optimized around a long-running engineering loop: understand the system, plan from evidence, execute with tools, inspect results, and continue until verification supports the change.

01

Repository-scale understanding

A published 2M-token context window provides room for source, configuration, documentation, and task state across large repositories.

02

Adaptive planning

Plans can be revised as commands, tests, diffs, or newly discovered files invalidate earlier assumptions.

03

Tool execution

Search, code inspection, terminal execution, and test feedback are treated as part of the engineering reasoning loop.

04

Verification-heavy completion

Neptune is positioned to continue past the first plausible patch and use observed evidence to determine whether work is complete.
