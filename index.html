Choosing a model

If you're not sure where to start, use Zorix Nex Coder 3.8 Neptune for difficult coding and software engineering work. Choose Mercury when cost and throughput matter, Virexa 3.5 for image generation, or NexHate 2 for translation.

API availability differs by model. Neptune is $12 per 1M input tokens and $47 per 1M output tokens. Mercury is $6 per 1M input tokens and $8 per 1M output tokens. Virexa 3.5 and NexHate 2 do not currently publish API pricing.
