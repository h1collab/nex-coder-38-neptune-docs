Faceless 2 · Reveal 2

Armed Response.

Faceless 2 is not only about avoiding an entity. The current build adds direct combat against armed security and a weapon system with two distinct firearms.

Combat

Pistol. Rifle. Aim. Reload. Switch.

Pistol12-round magazine
Rifle30-round magazine
AimingDedicated ADS state and FOV change
Weapon handlingReload animation + recoil + switching
EnemiesArmed security soldiers
EscalationReinforcements + final counterattack

The current v6 work includes pistol and rifle viewmodels, aiming, reload logic, weapon switching, gunfire audio, hit detection, ammunition pickups, medkits, patrol soldiers, reinforcement waves, kill tracking, and a final security counterattack at the dead-zone gate.

Faceless itself remains part of the pressure. The current AI can patrol, chase, attack, and be temporarily disrupted by gunfire before returning.

Source basis: current player.gd, soldier.gd, faceless.gd, and v6 commits in h1collab/ggme.
