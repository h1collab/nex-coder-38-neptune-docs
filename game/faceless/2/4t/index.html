Faceless 2 · Reveal 4

Modes & systems.

The current build already contains multiple play modes and a much broader set of player-facing systems than the first game.

Systems

Six modes, checkpoints, mobile-first controls.

Mode 01Story
Mode 02Rush
Mode 03Nightmare
Mode 04Endless
Mode 05Exploration
Mode 06Blackout
PersistenceCheckpoint save / continue
Mobile UIInteract, fire, reload, light, crouch, run, aim, swap
SettingsQuality, FPS, brightness, night visibility, FOV, sensitivity
Audio feedbackGunfire, reload, footsteps, heartbeat, radio

Nightmare increases difficulty and reduces starting battery. Exploration removes the Faceless hunter. Blackout starts with lower battery. The build also exposes performance and visibility controls, including 30/60/120 FPS choices, quality presets, field of view, brightness, and night visibility.

Source basis: current mode panel, settings panel, save system, mobile controls, and v6 audio commits in h1collab/ggme.

Status

Still in development.

These reveals describe the current repository state, not a locked launch specification. Systems, names, balance, assets, and release scope can still change.
