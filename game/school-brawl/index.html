Gameplay

Clear the room.
Then survive the next wave.

Fast actionHIT

Quick attack pressure with lower stamina cost.

Heavy actionKICK

Higher damage and stronger knockback at a greater stamina cost.

LoopWAVES

Defeat all teacher NPCs. A harder wave begins automatically.

ScoringCOMBOS

Chain successful attacks to increase combo count and score.

Player stateHEALTH + STAMINA

Sprint and heavy attacks consume stamina; enemy hits reduce health.

FailureROUND RESTART

Knockout resets the round, wave, score, combo, and player state.

Environment

A classroom built as the arena.

The current Sketchfab-rebuild direction uses a reconstructed classroom shell and high-detail GLB assets for visible geometry, with an invisible collision shell underneath.

Controls

Built for touch and desktop.

Android / touch

Move, look, hit, kick.

Landscape orientation, left virtual joystick for movement, right-side drag for looking, plus dedicated HIT and KICK controls.

Desktop

WASD + mouse.

Keyboard movement, Shift sprint, captured mouse look, with the same first-person movement model.

Build

Android builds through GitHub Actions.
