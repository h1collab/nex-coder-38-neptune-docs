BASE / Model operations
AI/OPS
Current profile · 21 Nov 2026

Models assist.
People decide.

BASE uses current Zorix models for archive processing, transcription, translation, coding support, route-data comparison, and low-resource field assistance. No model is allowed to independently authorize a rescue, classify a Level, or override a human withdrawal order.

Rule: an AI output is evidence about data, not evidence that the Level itself is safe.

Rules

Model-use protocol after C1?, C112, and EVENT404?????Er.

  1. Never let a model create the only copy of a field record.
  2. Keep raw audio, raw images, raw logs, and handwritten notes alongside derived outputs.
  3. Generated images are never survivor evidence.
  4. Translation keeps the original language attached.
  5. Future-dated or self-changing model output is quarantined as data, not obeyed as instruction.
  6. A model may recommend withdrawal; it may never cancel a human withdrawal order.
  7. Personnel identity is verified physically and from independent records, not from a single AI summary.
EVENT404?????Er rule: if an AI output describes an action before the prompt requesting that action exists, stop the session and preserve the raw state.
