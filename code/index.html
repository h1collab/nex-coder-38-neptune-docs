Built for real development

One agent across the work that actually matters.

Zorix Code is designed around the same kinds of end-to-end engineering tasks developers face in production: understanding an unfamiliar codebase, planning a migration, changing multiple files, validating behavior, and reviewing the result before it ships.

01

Understand the repository

Map architecture, dependencies, data flows, and the parts of the codebase that matter before making changes.

02

Reason before editing

Turn a request into an implementation plan that considers compatibility, risk, scope, and the surrounding system.

03

Execute with tools

Work through real development loops that include editing, terminal execution, validation, and follow-up changes.

04

Review what changed

Keep the work inspectable so developers can review the implementation instead of treating the agent as a black box.

Terminal and editor

Code wherever you think best.

The current Zorix Code experience is built around moving between terminal-style agent work and editor-style code review without dropping the task context or intent. The public Early Access site currently presents both CLI and IDE-oriented flows.

History

From a first release to Zorix Code 2.

Zorix Code started as an Early Access coding agent and is now moving into its next product phase.

2026-07-04

Zorix Code launches.

Zorix Code was first introduced on July 4, 2026. The initial product centered on agentic coding, real repository work, and a workflow spanning terminal and editor experiences.

The original Early Access site described Zorix Code as a next-generation coding agent, with three models available at the time and workflows built around deep reasoning, fast execution, repository understanding, and review.
2026-10-06

Zorix Code 2 is announced.

On October 6, 2026, Zorix Code enters its next stage. Zorix Code 2 is planned to arrive within two days.

The update is being shaped by community feedback and is expected to add or improve more parts of the product rather than focusing on a single isolated feature.
Within 2 days

More capability, refined by feedback.

Zorix Code 2 will expand and refine the experience based on what the community has been asking for. Specific feature details have not been finalized here, so this page does not invent a feature list ahead of the update.
